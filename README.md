# 案头

Windows 桌面控件。常驻在屏幕上，显示高考倒计时、番茄钟、比特币价格和上证指数走势。

窗口无边框。鼠标放在窗口上时逐渐变为不透明，移开后渐变回半透明，底下的内容可以透出来。默认置顶。

## 功能

- **高考倒计时**：按北京时间计到每年 6 月 7 日 09:00。6 月 7 日 09:00 至 6 月 8 日 18:00 显示为进行中。
- **番茄钟**：专注 25 分钟，短休 5 分钟，每 4 个专注后长休 15 分钟。到点播放一分钟闹钟，下一阶段要手动开始。响的时候可以点「停止」关掉声音，不会因此开始下一轮。
- **新建番茄钟**：点「新建」后在弹窗里填写任务。确认后开始一轮专注。若上一轮还没结束，会按原描述记为已中断。
- **番茄钟记录**：记下起止时间、任务描述和状态（进行中、已暂停、已完成、已中断）。
- **比特币**：芝麻开门（Gate.io）的 BTC/USDT 价格和走势，并按汇率折成人民币。涨为红色，跌为绿色。
- **上证指数**：腾讯行情。可在日 K 和分时之间切换。休市、交易中会标在行情上。

标题栏整栏可拖动。右侧图标依次是置顶、刷新、收起/展开、关闭。收起和展开只在点击时切换，鼠标悬停不会改变。右键菜单里也可以刷新、收起、置顶和退出。按 F5 立即刷新行情。

收起后，番茄钟正在计时时，标题栏会显示剩余时间。

## 运行

需要 Windows 和较新的 Rust（2024 edition）。

```bat
cargo run --release
```

行情约每 20 秒更新一次。

## 打包安装

安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 后，双击 `pack.bat`。脚本会先编译发布版，再生成安装包：

```text
target\installer\desk-setup-0.1.0.exe
```

安装到当前用户的 `%LOCALAPPDATA%\案头`，不需要管理员权限。安装时可勾选桌面快捷方式和登录时自动启动。

## 数据

窗口位置、置顶、收起状态、行情图选择和番茄钟记录保存在：

```text
%APPDATA%\desk-widget\data\app.ron
```

行情来源：

| 内容 | 来源 |
| --- | --- |
| 上证指数、美元兑人民币 | 腾讯行情 `qt.gtimg.cn` |
| 比特币 | 芝麻开门 `api.gateio.ws` |
